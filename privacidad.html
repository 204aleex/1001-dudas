Política de privacidad

Última actualización: 28 de octubre de 2026

«Programador 1001 Dudas» es una herramienta personal que usa únicamente el creador del canal 1001 Dudas para publicar sus propios vídeos en sus propias cuentas de YouTube, TikTok e Instagram. No tiene otros usuarios.

Qué datos usa

  • Permisos de acceso (tokens OAuth) de las cuentas del canal en YouTube, TikTok e Instagram, que el dueño concede al conectarlas.
  • Datos básicos de esas cuentas: el identificador y el nombre del canal o del perfil, para saber dónde se publica.
  • Los vídeos del canal y sus textos (título, descripción y hora programada).

No recoge datos de espectadores, seguidores ni de ninguna otra persona.

Para qué los usa

Solo para subir y publicar los vídeos del canal a la hora programada y para comprobar si se han publicado bien. Los datos no se venden, no se comparten con terceros y no se usan para publicidad.

Dónde se guardan

En una base de datos privada del propio creador, alojada en Supabase, con acceso restringido a su cuenta. Los vídeos se borran del almacenamiento unos días después de publicarse.

Servicios de Google y YouTube

Esta herramienta usa los Servicios de la API de YouTube. Al usarla se aplican las Condiciones del Servicio de YouTube y la Política de Privacidad de Google.

El uso y la transferencia de la información recibida de las API de Google cumplen la Política de Datos de Usuario de los Servicios de las API de Google, incluidos los requisitos de uso limitado.

Cómo retirar el acceso

El permiso se puede retirar en cualquier momento desde la propia herramienta («Desconectar») o desde cada plataforma, por ejemplo en la configuración de seguridad de Google. Al desconectar una cuenta, se borran sus tokens guardados.
